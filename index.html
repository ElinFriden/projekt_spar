Läs mer om vår hållbarhet

För oss handlar hållbarhet om mer än bara material. Det handlar om hur vi designar, producerar och levererar våra produkter.

Vissa av våra produkter tillverkas med Biogarmentry, ett innovativt textilmaterial utvecklat med levande mikroalger. Algerna kan genomföra fotosyntes när de utsätts för ljus.

På så sätt absorberar de koldioxid och avger syre, precis som växter i naturen.
